# Language icons

The solar-system card inlines these marks inside its planet spheres.

- Source: [Simple Icons](https://simpleicons.org/)
- Licence: CC0 1.0 Universal
- Files: `typescript.svg`, `css.svg`, `python.svg`, `javascript.svg`, `rust.svg`

The generator reads the path data from these files at build time, so the
workflow never downloads an icon or depends on a CDN.
